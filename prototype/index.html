09 · Accordion (exclusive <details>, no JS)

Does it need a build step?

No. Link one CSS file and one JS file. A build step is only there if you want to pick individual modules.

Which browsers are supported?

Current Chrome, Edge, Safari and Firefox. Newer features like anchor positioning enhance progressively.

Can I make my own direction?

Yes. A direction is a block of about 40 tokens. Copy one, change the values, and every component follows.

10 · Theming

Two attributes. That's the whole API.

Set a direction and a theme on the root element. Colours use light-dark(), so each direction defines both themes in one place. The customizer exports any token overrides as a small :root block.

HTML
<html data-direction="soft" data-theme="dark">
  <link rel="stylesheet" href="vectra.css">
  <script src="vectra.js" defer></script>
