Vectra v2 · alpha

One markup. Four directions. Nothing to install at runtime.

Vectra is a UI kit built on the web platform: native <dialog>, popover and <details>, one CSS file and one small JS file, self-hosted fonts and icons. Change one attribute and the whole interface takes on a new design direction, in light and dark, at WCAG 2.2 AA.

Install in 30 seconds

  1. Get the files. Download the release zip and copy dist/ into your site, or install from npm.

    npm install @creativeigniter/vectra

  2. Link one CSS file and one JS file. Keep fonts/ and icons/ next to the CSS.

    <link rel="stylesheet" href="/vectra/vectra.css">
<script src="/vectra/vectra.js" defer></script>

  3. Pick a direction. tech, editorial, soft or glass. Leave out data-theme and light or dark follows the OS.

    <html lang="en" data-direction="editorial">

That is the whole setup. Write <button class="v-btn v-btn-primary"> and you have a Vectra button. Getting started covers production builds, Laravel Blade, Vue and Inertia, Livewire and htmx.

How it is built

Platform first

The native element wherever one exists. JS only adds what HTML cannot do.

Tokens drive everything

Components never hard-code colour, radius, spacing or type. A direction is a token set plus a few flourishes.

Accessible by construction

Contrast is built into the OKLCH token maths, so any accent hue stays at AA.

Flat specificity

Cascade layers and single-class selectors, so your own CSS wins without a fight.
