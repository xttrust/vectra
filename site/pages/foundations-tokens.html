Every colour, radius, shadow and font in Vectra is a custom property. Components read tokens and never hard-code a value, so a direction is just a token set.

Three tiers

  • Primitives are shared by every direction: the type scale, the space scale times --v-density, motion, status colours. See Typography and Spacing.
  • Semantic tokens are the contract below: surfaces, borders, text, accent, radii and shadows. Each direction defines them for light and dark with light-dark().
  • Component tokens default to semantic ones, for example --v-btn-radius: var(--v-radius-md). Set one on a selector to restyle that component alone.
.pricing {
  --v-card-bg: var(--v-surface-2);
  --v-btn-radius: var(--v-radius-pill);
  --v-density: 0.9;
}
