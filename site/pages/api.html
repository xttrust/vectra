Reference

JavaScript API

With dist/vectra.js everything below is on window.Vectra. With a bundler, import the same names from dist/vectra.esm.js. Nothing else is added to the global scope.

How modules start

Components declare behaviour with data-v-* attributes. When the script loads, the core finds every hook and starts its module; a MutationObserver starts hooks added later and tears down those removed. Every module exports init(el, options) and returns { destroy }.

Vectra.init(root = document)

Starts every registered module inside root. Safe to call repeatedly: an element that is already running is left alone. You rarely need it, since added content starts on its own.

const panel = document.querySelector('#settings');
panel.innerHTML = await (await fetch('/settings/partial')).text();
Vectra.init(panel); // optional: the observer would start it a moment later anyway

Vectra.register(name, setup)

Adds a module for data-v-<name>. setup(el, options) runs once per element and may return { destroy }, called when the element leaves the page. Elements already on the page start straight away.

Vectra.register('autosize', (el) => {
  const fit = () => { el.style.height = 'auto'; el.style.height = `${el.scrollHeight}px`; };
  el.addEventListener('input', fit);
  fit();
  return { destroy: () => el.removeEventListener('input', fit) };
});
// <textarea class="v-input" data-v-autosize></textarea>

Vectra.emit(el, type, detail)

Fires a bubbling, cancelable v:<type> event and returns false if a listener called preventDefault(). The kit's own events: v:theme, v:dismiss, v:change, v:dirty.

document.addEventListener('v:dismiss', (e) => {
  if (e.detail.key === 'trial-banner' && !confirm('Hide this for good?')) e.preventDefault();
});

Vectra.storage.get(key, fallback), .set(key, value)

localStorage under a vectra- prefix that never throws, so private mode or blocked storage only means the setting lasts for this page. Setting null removes the key.

Vectra.announce(message, politeness = 'polite')

Reads a message to screen readers through a shared live region. Use 'assertive' only for urgent news. Repeating the same message announces it again.

Theme

Vectra.theme.get(), Vectra.theme.set(changes)

get() returns { direction, mode, accent, corners, density, font, resolved }, where resolved is the theme showing (light or dark). set() takes any of those keys, ignores unknown values, saves them and emits v:theme on <html>. Direction and mode changes run in a view transition where supported, and instantly under reduced motion.

Feedback

Vectra.toast(message, options)

Shows a toast and returns { dismiss }. Options: tone (success, info, warning, danger), action: { label, onClick }, undo (a function, shorthand for an Undo action) and duration in ms (0 keeps it until dismissed). A toast with an action stays at least 10 seconds, timers pause on hover and focus, and up to three show at once. Toast.

Vectra.toast('Project archived', { undo: () => restore(id) });
Vectra.toast('Payment failed', { tone: 'danger', duration: 0 });

Vectra.connection.slow(on = true)

Shows or clears the slow-network notice in every data-v-connection banner. Offline and back online are detected by the browser events. Connection banner.

Vectra.session.warn({ expiresAt, onExtend, onExpire, onSignIn })

Opens a modal alert dialog with a countdown, announced at minute marks and at 30 and 10 seconds (WCAG 2.2.1). Returns { close }. Session timeout.

Vectra.session.warn({
  expiresAt: Date.now() + 2 * 60 * 1000,
  onExtend: () => fetch('/session/refresh', { method: 'POST' }),
  onSignIn: () => { location.href = '/login'; },
});

Vectra.saveStatus(el, state, { at })

Sets an inline .v-save-status to saving, saved, failed or offline. Saved shows the time since at and keeps it fresh. Save status.

Vectra.fieldState(input, state, message)

For async checks: checking, valid, invalid or clear. Writes the message under the field, links it with aria-describedby and announces it. invalid also blocks the form from submitting until the check passes. Async field check.
