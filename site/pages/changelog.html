Changelog

From v2.0 this page is written from the release tags. Until then, the milestones merged so far.

Unreleased: 2.0.0-alpha.0

  • M6a, docs site. This site: a page per component from one data file, foundations, the JS API, migration guide and search.
  • M5, icons and fonts. A Lucide-based SVG sprite with a subset tool, and self-hosted Inter in latin and latin-ext subsets.
  • M4, JavaScript. The core (auto-init, observer, events, storage, announcements), form behaviour, theming, toasts, connection, session and save status.
  • M3, components. Every static P0 component, on seven gallery pages tested in all directions and themes.
  • M2, foundations. Reset, base type, layout primitives and utilities.
  • M1, tokens. The token contract, four directions and the accent hue correction.
  • M0, tooling. CI, size budgets, the external URL check and the test harness.
