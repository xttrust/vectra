Migrating from v1

Vectra v1 was a dark, cyan theme on top of Bootstrap 5. v2 is a new kit from scratch on the web platform. Most class names keep the v- prefix and mean the same thing; the Bootstrap layer underneath is gone.

What changed

  • No Bootstrap, no Font Awesome, no CDN. Remove both stylesheets and the Bootstrap bundle. Icons come from Vectra's own SVG sprite.
  • Native elements instead of Bootstrap JS. Modals become <dialog>, dropdowns and the mobile menu become popover, accordions become <details name>. Remove every data-bs-* attribute.
  • Four directions. v1's look lives on as the tech direction, the default. Add data-direction on <html> to choose another.
  • Light and dark everywhere. v1 was dark first with a light override. In v2 every direction has both, and without data-theme the OS decides.
  • States by attribute. .active, .show and .disabled give way to aria-current, aria-selected, open and disabled.
  • The grid. Bootstrap's row and col-* go. Use v-grid (as many columns as fit), v-sidebar, v-switcher or v-bento. See Layout primitives.

A typical swap

A v1 modal:

<button class="v-btn v-btn-primary" data-bs-toggle="modal" data-bs-target="#invite">Invite</button>
<div class="modal fade" id="invite" tabindex="-1">
  <div class="modal-dialog modal-dialog-centered"><div class="modal-content">
    <div class="modal-header"><h5 class="modal-title">Invite</h5><button class="btn-close" data-bs-dismiss="modal"></button></div>
    <div class="modal-body">...</div>
  </div></div>
</div>

The same in v2, on the native dialog. Focus trap, Escape and focus return come from the browser.

<button class="v-btn v-btn-primary" type="button" onclick="invite.showModal()">Invite</button>
<dialog class="v-dialog" id="invite" aria-labelledby="invite-title">
  <header class="v-dialog-header">
    <h2 class="v-dialog-title" id="invite-title">Invite</h2>
    <form method="dialog"><button class="v-btn v-btn-ghost v-btn-icon v-dialog-close" aria-label="Close">...</button></form>
  </header>
  <div class="v-dialog-body">...</div>
</dialog>
