Vectra icons

Icons

One sprite, no icon font.

Every icon in dist/icons/sprite.svg, drawn from Lucide (ISC). Icons take the text colour and scale with the font size.

Usage

Reference a symbol by name. Add aria-hidden="true" when the icon sits next to text, or give the button an aria-label when it is the only content.

HTML
<svg class="v-icon" aria-hidden="true"><use href="/icons/sprite.svg#search"/></svg>

Ship only the icons a site uses: npx vectra-icons "pages/**/*.html" --out icons.subset.svg writes a sprite with the symbols those pages reference.
