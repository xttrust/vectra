API · Getting started

Introduction

The Northwind API lets you read and write customers, jobs and invoices from your own software. It speaks JSON over HTTPS.

Authentication

Create a key in Settings, API keys and send it as a bearer token. Keys belong to a workspace, not a person. The examples read the base address and the key from NORTHWIND_API and NORTHWIND_KEY.

Shell
curl "$NORTHWIND_API/v1/customers" \
  -H "Authorization: Bearer $NORTHWIND_KEY"

Your first request

List the ten most recent customers. Every list is paginated with cursor and limit.

JavaScript
const res = await fetch(`${process.env.NORTHWIND_API}/v1/customers?limit=10`, {
  headers: { Authorization: `Bearer ${process.env.NORTHWIND_KEY}` },
});
const { data, next_cursor } = await res.json();

Rate limits

Each key can make 120 requests a minute. Past that you get a 429 with a Retry-After header.

Next steps
