Accordion and collapsible

Do I need JavaScript for this?

No. The accordion is native details elements sharing one name, so opening one closes the others.

Can several items be open at once?

Leave out the name attribute and every item opens on its own.

Does it animate?

Where the browser supports it, the height eases open. With reduced motion it opens at once.
