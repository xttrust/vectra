Use any flow in any layout

Copy the .v-auth-box from a flow page and drop it into the layout you want: change the class on the wrapper, and add an aside for the split screens. In a dialog, the box goes straight inside <dialog class="v-dialog v-auth-dialog">.

HTML
<!-- Pick the layout on the wrapper. The box inside is the same for every layout. -->
<div class="v-auth v-auth-split">
  <main class="v-auth-main">
    <a class="v-auth-logo" href="/">...</a>
    <div class="v-auth-box">...</div>
    <footer class="v-auth-footer">...</footer>
  </main>
  <aside class="v-auth-aside v-auth-art">...</aside>
</div>

For Laravel: the fields are named email, password, password_confirmation, remember, code, recovery_code and token, as Breeze and Fortify expect. Each form has a comment where @csrf goes, and server errors sit under their field with aria-invalid, like the wrong password page.
